# 2026-07-10 修改記錄

## 新增：COMB（外部已切分）資料集的貼標籤流程

### 背景

新增 `datasets/processed/COMB/split/{train,test}.txt`，是已經由外部流程切好 train/test 的原始密碼清單（未清洗、未貼標籤），與現有 `run_pcfg_segment.py`「先全量貼標籤 → 再抽樣切 train/test」的順序相反，無法直接套用既有腳本。

### 新增檔案 — `run_pcfg_tag_presplit.py`

在不重新抽樣、不打亂既有 train/test 歸屬的前提下，對已切分好的資料集進行清洗 + 貼標籤：

1. **移除含 `|` 的密碼**：密碼原文若含 `|`，會與 `Tokens`/`Tags` 欄位用來 join 的分隔符衝突，造成無法還原的壞資料（例：`"sssham80 | 1"` → `Tokens: "ss|sham|80| | |1"`），故直接剔除
2. **移除 PW_WORD 字元集以外的密碼**：比對 `util/pw_tokenize.py:get_alpa()` 的 `PW_WORD`（模型實際可編碼/生成的 94 字元表）
3. **內部去重**：`train.txt`、`test.txt` 各自 `drop_duplicates`（沿用 `util/data.py` 的 `remove_duplicates` 邏輯）
4. **移除 train/test 洩漏**：從 `test.txt` 中移除同時存在於 `train.txt` 的密碼
5. **貼標籤**：沿用 `src/PCFGSegment.py` 的 `PCFGSegmenter`，對 `pos` / `backoff` / `pos_semantic` 三種 tagtype 分別處理 train / test
6. **輸出**：
   - 中繼 CSV：`gen/semanticPCFG/COMB_{split}_{tagtype}_tagged.csv`
   - 最終 JSONL：`datasets/processed/semanticPCFG/COMB/{tagtype}/split/{train,test}_data.jsonl`（欄位對齊既有格式：`Password, Tokens, Tags, source`）

未修改 `config/pcfg_segment.yaml`（依使用者要求，presplit 相關路徑直接寫死在腳本內，不污染共用 config）。

### 修正：字元集檢查基準從 `util/data.py` 改為 `PW_WORD`

一開始誤用 `config/config.yaml` 的 `password_cleaning.allowed_charsets`（`util/data.py:clean_data()` 的規則）做字元集過濾，移除了 311 筆含空格的密碼（train 303、test 8）。後來發現這規則跟訓練/推論階段實際使用的字元表 `util/pw_tokenize.py:get_alpa()` 的 `PW_WORD` **不一致**：

- `PW_WORD`（94 字元，模型真正能編碼/生成的字元）：**允許空格**、**不允許冒號 `:`**
- `util/data.py` 的 `allowed_charsets`：**不允許空格**、**允許冒號 `:`**

`PW_WORD` 才是正確的判斷基準，因為它直接對應 `get_alpa()` 建立的 token-ID 對照表。已改用 `PW_WORD` 重新過濾並確認 COMB 原始資料中沒有冒號，因此唯一的實際影響是把先前誤刪的 311 筆含空格密碼恢復。

### 執行結果（dataset=COMB，最終版）

| 階段 | train | test |
|---|---|---|
| 原始筆數 | 284,072 | 14,950 |
| 移除含 `\|` 密碼後 | 284,016 | 14,949 |
| 移除 PW_WORD 以外字元後 | 284,016 | 14,949 |
| 內部去重後 | 262,265 | 14,555 |
| 移除 train/test 重疊後 | 262,265 | 13,513 |
| 長度過濾 [8,20] 後（三種 tagtype 皆同） | 262,263 | 13,513 |

- 含 `|` 的密碼：train 56 筆、test 1 筆（0.02%），已剔除
- PW_WORD 以外字元：0 筆（COMB 原始資料未含冒號等 PW_WORD 排除的字元）
- 含空格的合法密碼：train 303 筆、test 8 筆，保留
- train/test 重疊移除：14,555 → 13,513
- 事後驗證：三種 tagtype 的 train/test JSONL 均無 `|`、均無 PW_WORD 以外字元、train/test 密碼集合交集為 0
- 三種 tagtype（pos / backoff / pos_semantic）皆已產生，執行時間約 1m46s（含 `--force` 重跑）

### 用法

```bash
python run_pcfg_tag_presplit.py                    # dataset=COMB，全部 tagtype
python run_pcfg_tag_presplit.py --dataset COMB --tagtype backoff
python run_pcfg_tag_presplit.py --force             # 強制重跑（忽略既有 CSV cache）
```
