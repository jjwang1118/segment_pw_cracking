## 新增分析：PassLLM 猜中密碼的姊妹密碼組成（COMB）

- **修改** `docs/reports/comparison_PassLLM_vs_PCFG-LLM_COMB.md`
  - 新增第 6 節「PassLLM 猜中密碼的姊妹密碼組成分析」
  - 資料來源：`gen/passllm/run_01/input_output.jsonl`（依 `model_input` 中 `"Old password"` 欄位是否為空陣列判定有無姊妹密碼，依密碼去重後 5,000 筆，與既有報告一致）
  - 結果：@1000 猜中的 1,054 筆中，1,051 筆（99.7%）帳號有姊妹密碼，僅 3 筆無姊妹密碼；@10/@50 猜中密碼 100% 皆來自有姊妹密碼帳號
  - 結論：PassLLM 高度依賴同帳號舊密碼線索，與本研究 PCFG-LLM（不依賴舊密碼、僅憑結構 tag）鎖定不同威脅情境

## 新增三方比較：PassLLM 新／舊 Prompt vs 本研究 PCFG-LLM（COMB）

- **修改** `docs/reports/comparison_PassLLM_vs_PCFG-LLM_COMB.md`
  - 新增第 7 節「三方比較：PassLLM 新／舊 Prompt vs 本研究 PCFG-LLM」
  - PassLLM 新增 `gen/passllm/run_02/`（新 prompt：移除 `Old password` 的 JSON 包裝，姊妹密碼改以 `</s>` 逐一串接），與既有 run_01（舊 prompt：`json.dumps` 包裝）對照；兩次評估共用同一 checkpoint（`checkpoints/mistral_7b_COMB/final`）與同一評估設定，僅 prompt 內容格式不同
  - **資料處理注意**：`gen/passllm/run_02/passllm_run2_COMB.json` 實為 run_01 全部 5,054 筆 + run_02 自己 5,000 筆串接而成（共 10,054 筆），已取檔案末尾 5,000 筆（真正 run_02 資料）計算，並與 `gen/passllm/run_02/eval-260642_params_summary.md` 官方數字（650/5000, 13.00% @1000）核對一致
