## `docs/multi_structcand_tagtype_test.md` — 新增（multi-structcand 前置測試記錄）

**動機：** `multi-structcand` 分支「讀法 A（1 pw → N 候選結構）」的前置驗證。測試同一密碼在三種 tag-type（`pos` / `backoff` / `pos_semantic`）下的結構差異，判斷「三種 tag-type 併陳」是否為有效的 N 來源。

**內容：** 測試設定（rockyou-75、8–20 長度過濾、seed 42、100 筆）、統計摘要、核心結論、完整 100 筆原始結果表。

**主要發現：**
- 三種 tag-type 間切分（segmentation）100% 一致（0/100 不一致）。
- 平均每筆 2.66 個不同 tag 字串，但這是「同一結構的三種抽象層級」（`pos` ⊂ `pos_semantic`；`backoff` 為語意層），非競爭候選。
- 真正價值：三者「互補」——`backoff` 保留 mname/surname/city，`pos_semantic` 對專有名詞塌成 `np1_unk`；併陳嚴格多於單一種資訊。
- 真正的競爭候選結構需另尋來源（多重 segmentation、`PCFGSegment.py:118` `synsets[0]`→top-k 多義、PCFG parse 分布）。

**未更動任何 code / config；** 測試腳本 `tag3modes.py` 置於 scratchpad，未進版控。
