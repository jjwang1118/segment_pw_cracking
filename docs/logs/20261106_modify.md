## 新增：純 plaintext 無條件分布學習（full fine-tune）

目標為學 p(password) 的分布，採 MLE = causal-LM cross-entropy，不使用 LoRA。

- 新增資料集 `datasets/processed/plaintext/split/{train,test}_data.jsonl`
  - 來源 `passwords_no_test.txt`，再過濾長度 8–20 + 字元集 → 2,744,193 筆
  - 隨機（seed=42）切出 10,000 筆作 held-out（eval_loss / perplexity），其餘 2,734,193 筆為 train
  - 每行格式 `{"Password": "..."}`（無 tags / siblings，純無條件）
- 新增 `config/train_plaintext.yaml`：full FT 超參（LR 1e-5、epoch 2、label_smoothing 0、max_length 48、no LoRA）
- 新增 `run_train_plaintext.py`：獨立全參數微調腳本
  - 無條件 tokenize：`input = [bos] + encode_limit(pw) + [eos]`，bos 不計 loss，其餘整串計 loss
  - 字元編碼沿用 `util.pw_tokenize.encode_limit`（95-char 映射，與 search/eval 一致）
  - 輸出至 `checkpoints/{model}-plaintext/run_N/final`（存完整權重）
- 新增 `train_plaintext.sh`：SLURM 啟動（以 train_h200.sh 為底，單卡 H200）
- 已做 tokenize smoke test（bos 遮罩、密碼字元+eos 計 loss）通過。

備註：原有 `config/train_config.yaml`、`run_train.py`、LoRA/條件式流程皆未更動。
